# Fake News Detection 📰
ML model to classify news as real or fake.

## Tech Stack
Python, Scikit-learn, NLP, TF-IDF, Logistic Regression

## Accuracy
Achieved 90% training accuracy

## Dataset
Dataset sourced from Kaggle - too large to upload to GitHub

## How it works
- Text preprocessing and cleaning
- TF-IDF vectorization for feature extraction  
- Logistic Regression for classification
